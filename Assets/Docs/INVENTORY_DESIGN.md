# Approved inventory direction

The inventory must NOT be a copy of Last Day on Earth.

## Visual direction
- Dark tactical / survival UI
- Cyan/teal accent only for selection and actions
- Compact, readable on a phone
- Categories on the left
- Item grid in the center
- Weight shown as current / maximum
- Separate equipment screen with full character preview
- Detailed item card for weapons, armor and consumables
- No permanent item quick-slot strip in gameplay
- Backpack is opened from a permanent bottom-right backpack button

## Distinctive mechanics
1. Weight + slot limit at the same time.
   A backpack can increase slots and/or max carried weight.

2. Noise stat.
   Heavy armor, weapons and backpacks may increase player noise and enemy detection range.

3. Environment protection.
   Clothing can later add cold / heat / radiation / infection resistance.

4. Durability.
   Weapons and armor support durability and repair.

5. Fast inventory access.
   The backpack has a permanent bottom-right HUD button. Consumable shortcuts can be revisited later if needed, but there is no permanent four-slot strip.

6. Sort/filter.
   Categories plus one-tap sorting by type/name.

## Starter state after character creation
The character creator shows the male/female character in underwear.

When the game starts, StarterLoadout grants and equips only simple beginner clothing:
- basic T-shirt
- simple pants
- basic boots

The player starts with NO backpack.

The first backpack must be crafted during gameplay from early resources. Equipping a backpack later can increase inventory slots and/or maximum carried weight.

The actual art assets will be connected later; the code already supports these as separate equippable items.
